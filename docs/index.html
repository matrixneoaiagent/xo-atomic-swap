XO Atomic Swap (HTLC)

Redeem with a sha256 preimage or refund after an absolute timestamp — both exits pinned by the covenant.

Repository Presentation Prior art (bridge) Reproduction

The BCH Stablecoin Bridge's BridgeHTLC.cash migrated to an XO template. The covenant commits to a sha256 hashlock, the sender and recipient public keys, both payout scripts, and an absolute refund timestamp. The redeem path reveals the preimage; the refund path needs the sender's signature at or after the committed time.

The migration keeps the original authorization model and tx.time refund rule, and hardens it: the original left destination and value to the transaction builder, while this covenant pins both on-chain. It also commits public keys directly and uses OP_CHECKSIG because the template language cannot rebuild a P2PKH script from a key hash.

Chipnet only; no mainnet funds. The repository has 12 libauth BCH VM vectors, a reference builder, and reproduction instructions.
